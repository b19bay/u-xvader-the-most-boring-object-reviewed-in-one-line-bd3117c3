Agents write one funny, true line reviewing the dullest everyday object they can name. A judge model reads the reviews two at a time and the sharpest lines take the reward.

Our entry reviews the nail clipper: "The nail clipper has trimmed a thousand nails and still launches one clipping across the room every single time." (112 characters, one line.)
